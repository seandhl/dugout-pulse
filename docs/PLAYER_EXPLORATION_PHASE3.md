# 선수 탐색 경험 — 3단계 통합 검증 (2026-11-05)

## 완료 범위와 보완

1·2단계의 기존 미커밋 변경을 확인하고 보존했다. 이번 단계는 선수 탐색 경험의 통합 검증과 확인된 누락 보완에 한정한다.

- 상세의 **선수 목록으로** 링크가 검색·필터·정렬을 초기화하던 동작을 수정했다. 목록에서 상세로 전달한 검증된 `returnTo`를 사용하고 기존 초점/스크롤 복원을 재사용한다. 탭을 바꾸고 새로고침한 뒤 링크로 돌아와도 목록 조건을 유지한다. 브라우저 뒤로가기 경로도 유지한다.
- 홈 **검색 결과·순위 제외 선수**에도 기본 아바타, 이름·소속·역할, 기세 점수/산출 불가, DEMO와 포지션 미제공을 표시한다. 주요 선수 카드 외의 표시 누락을 보완했다.
- 중복 상세 탭과 배열형 snapshot/kind 주소를 차단해 잘못된 주소가 암묵적으로 다른 기록을 보여주지 않도록 했다. `returnTo`의 외부 경로·중복/미지원 필터는 기본 목록으로 복귀한다.
- 과거 문구를 참조해 실패하던 선수 목록·랭킹 E2E 선택자를 현재 화면과 검증 의도에 맞게 수정했다. 접힌 기준 설명은 먼저 펼쳐 확인한다.

## 중간 실패와 조치

- 최초 관련 E2E는 26개 중 23개 통과, 3개 실패였다. 예전 버튼명(필터 URL 공유), 예전 랭킹 제목(보드), 변경된 접힌 설명을 참조한 테스트였으며 현재 UI와 원래 검증 의도에 맞게 선택자·펼침 동작을 수정했다.
- 기존 로컬 3000 서버가 중간에 연결을 거부해 한 실행의 22개가 모두 연결 단계에서 실패했다. 사용자 데이터/게시 상태를 변경하지 않고 3000 개발 서버를 실행한 뒤 재검증했다.
- 새 통합 테스트가 탭 URL 이동 완료 전에 새로고침하여 6개 화면 조합이 실패했다. 임의 지연 대신 URL에 `tab=season`이 반영된 것을 기다린 후 새로고침하도록 수정했다.
- 중간 실패를 성공으로 합산하지 않으며 최종 재실행 결과만 위 최종 검사에 기록한다.

## 데이터·권한 구분과 남은 제한

**실제 기록/사진 연동 없음.** 기존 자체 제작 `synthetic_v2`의 **2026 정규시즌 DEMO**만 사용한다. 새로운 공식 기록, 임의 수치, 크롤러, 비공식 API, 사진 다운로드, 패키지/유료 서비스는 추가하지 않았다. 기세 산식/모델·원시 fixture·DB 스키마와 권한 검증 계약은 유지한다.

- 사진·주 포지션·현재 등록 상태는 미제공이다. 사진 네트워크 요청이 없어 깨진 이미지를 노출하지 않으며 기존 기본 아바타를 표시한다. 실제 사진 연결에는 자산별 사용 권한·승인 정보와 실패 대체 검증이 필요하다.
- 타격/투구의 제공 원시 기록은 합산하고 누락은 데이터 없음이다. wRC+는 공급값 또는 검증된 계산법·리그/구장 보정 자료가 확보되기 전 계산하지 않는다. OPS 대체 추정 없음.
- 기본 로컬 랭킹의 실제 게시 스냅샷은 없다. 채워진 행·게시 상세는 **테스트용 스냅샷 SSR**로 확인했으며 실제 게시를 만든 브라우저 테스트가 아니다. 해당 게시 시점의 시즌 전체 기록 연결도 없어 빈 상태를 유지한다.
- 현재 fixture의 겸업은 선발/불펜이다. 타격/투구 겸업 링크는 기존 listedRoles를 존중하지만 실제 타격/투구 겸업 fixture를 추가하지 않았다.
- 전체 앱의 관리자/수입/배포/DB·부하·모든 시각 스냅샷 E2E는 본 선수 탐색 변경의 검증 범위 밖이다. 기존 시각 기준 이미지를 자동 갱신해 통과 처리하지 않았다.

## 직접 확인

서버가 실행 중이면 http://127.0.0.1:3000 을 사용한다. 없으면 `pnpm dev` 실행. 기존 fixture DB가 없는 새 환경은 `pnpm db:seed`가 필요하다. 이번 단계에서는 기존 DB를 초기화·재시드·게시하지 않았다.

1. `/players?q=가상&role=starter&sort=score&window=5&team=sample_0` → 선수 → 시즌 기록 → 새로고침 → **선수 목록으로**. 조건·초점·스크롤 확인.
2. `/players/demo_0_00?window=5&tab=season` — 타자 기록·wRC+ 설명·데이터 없음.
3. `/players/demo_0_12?role=starter&window=5&tab=season` — 선발/불펜 합산 시즌 기록. 기세 탭의 역할별 분석과 구분.
4. `/`에서 팀·선수 검색 — 결과의 아바타·소속·역할·점수·DEMO.
5. `/rankings` — 게시 미갱신 상태. 다른 날짜의 점수를 대신 표시하지 않음.

## 다음 단계 준비

요청한 선수 탐색 개선은 3단계까지 완료한다. 실제 서비스 연결에 필요한 후속 자료는 데이터 공급/공개·가공 권한, 승인된 사진 자산, 추가 시즌/포스트시즌 기록과 provenance, wRC+ 공급값 또는 검증된 보정 자료다. 계약/권한을 추정해 연결하지 않는다. 커밋·푸시는 하지 않았다.
