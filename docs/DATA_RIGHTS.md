# 데이터 권리 및 공급 승인 대장

기준일: 2026-11-04 (Asia/Seoul). 현재 운영 모드: **DEMO**. 실제 소스에 대한 계약 증빙은 없다. 실제 데이터 수집·저장·가공·노출은 승인되지 않았다. 이 문서는 내부 승인 정책이며 법률 의견이나 공급 계약을 대신하지 않는다.

내부 엔드포인트 추측·역공학·스크래핑·자동 크롤링·접근 제한 우회는 구현 및 향후 계획에서 제외한다. 실제 데이터 경로는 아래 A/B/C 중 개별 승인된 경로만 허용한다. 수동 복사나 CSV 변환으로 권리 제한을 우회하지 않는다.

## 3. 실제 소스 승인 시 필수 증빙

공급자별로 위 대장의 모든 필드를 채우고 다음 항목을 추가한다. 계약서·비밀·개인 연락처 원문은 저장소에 넣지 않는다. 접근 통제된 증빙 보관소의 문서 ID·버전·해시·관련 조항·검토일·승인자 역할을 안전한 참조로 남긴다. 링크 존재만으로 승인하지 않는다.

- 이용 목적(기세 분석/공개 서비스), 필드·시즌·대회·기간·지역·서비스 도메인, 상업 이용 및 광고 여부.
- 수집/수입, 서버 저장, 임시본·캐시·로그·백업, 보관 기간, 가공, 원본 노출, 가공 결과 노출, 재배포/다운로드 각각의 허용/금지 및 근거 조항. 기능에 필요한 권리 하나라도 미확인이면 차단.
- 공급자의 권원 및 재허락 권한, 인증 방식, 요청 한도·갱신 주기, 정정/삭제 통지, 출처 표기 문구와 노출 위치.
- 효력 시작일·만료일·갱신 조건·해지/철회 조건, 종료 시 원본·파생물·캐시·백업 삭제 또는 보관 근거와 이행 기한.
- 지정 담당자, 법무 검토자·결과·검토일·대상 계약 버전, 운영 승인자·승인일, 재검토 조건. 무기한 계약은 근거와 다음 검토일을 명시.

승인은 소스·사용 범위·계약 버전에 한정한다. 새 필드·용도·공급자·상업화·노출 형태 변경은 재승인한다. 만료·철회·증빙 부재 시 신규 수입/게시/노출을 중단하고 마지막 실제 배치도 계속 노출하지 않는다. 권리 확인된 가상 배치로 전환하거나 빈 상태를 제공하며 삭제/보관 의무를 이행한다. 과거 실제 배치 복구에도 현재 유효한 권리가 필요하다.

## 4. 별도 자산 권리 대장

데이터 라이선스가 아래 자산까지 포함한다고 추정하지 않는다. 파일/사용 위치 단위로 공급자·출처 링크·제작자·라이선스·상업 이용·수정·재배포·표시 의무·만료·담당·법무 결과를 위 대장과 동일하게 등록한다.

| 자산 | 현재 증빙·결론 | 현재 조치 |
| --- | --- | --- |
| KBO/구단 엠블럼·로고·상표 | 없음, pending | 미사용; 가상 팀 이름과 자체 도형 사용 |
| 선수 사진·초상·프로필 이미지 | 저작권·초상 관련 허락 없음, pending | 미사용; 자체 도형 사용 |

| 폰트·아이콘·차트 라이브러리 | 아직 미선정/미설치, pending | 도입 시 라이선스 및 고지 파일 확인 |

## 5. 추적성과 현재 판정

향후 P2 계약은 `sourceId`, `rightsRecordId`, `batchId`, `isDemo`, 데이터 기준 시각 `asOf`, 별도 수입 시각, 시즌, 대회(정규시즌/포스트시즌), 표본 크기/단위를 필수로 한다. 파생 수치는 모든 원천 ID·배치·권리 기록·계산 버전을 보존한다. 이는 설계 요구이며 스키마 구현 완료가 아니다. 실제/가상 혼합 배치는 거부한다.

현재: **DEMO 전용 정책 승인 / 실제 데이터 전환 불가 / 공개 출시 미승인**. fixture와 앱이 아직 없으므로 D의 개별 산출물 검수도 미완료다. [출시 게이트](RELEASE_GATES.md)의 기계적 검사와 수동 검수를 모두 적용한다.
