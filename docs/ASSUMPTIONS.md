# 미확인 가정 추적

미확인 사항은 사실이나 권한으로 간주하지 않는다. 증거가 확보되면 상태와 근거를 갱신하고 필요한 ADR을 연결한다. 비밀·개인정보는 기록하지 않는다.

| ID | 가정/미확인 사항 | 상태 | 안전한 기본값 | 확인 시점·방법 |
| --- | --- | --- | --- | --- |
| A-001 | 데이터 공급 계약/승인이 없다 | 권한 미확인 | **데모 모드만 허용**; 외부 수집·연동 없음 | 실제 연동 전 사용 범위·기간·표시·저장·재배포 권한 증빙 검토 |
| A-002 | 서비스의 우선 대상은 한국어 KBO 팬이다 | 제품 기본 가정 | 한국어·모바일 우선 | P4 UX 검토 |
| A-003 | 실명 선수·팀 로고·사진 사용 권한 | 미확인 | 가상 식별자·텍스트·자체 UI만 사용 | 자산 도입 전 개별 권한 검토 |
| A-004 | Next.js + pnpm이 적합하다 | 기술 제안 | P0 설치 없음; P1에서 버전·지원 상태 확인 | P1 호환성·빌드 검증 및 ADR-003 갱신 |

| A-006 | 점수 윈도·최소 표본·가중치를 정할 수 있다 | 미결정 | 공식 지표로 주장하지 않고 P3까지 산식 확정 보류 | P3 역할별 산식 및 경계 테스트 |

## 확인된 사실과 구분

2026-11-03 진단에서 프로젝트는 빈 폴더였으며 package.json·lockfile·앱 실행 스크립트가 없었다. macOS 15.7.4 arm64, Node.js v26.11.0, npm 11.20.0, pnpm 12.10.1, Python 3.10.5가 확인되었다. 이 설치 사실은 향후 프레임워크 지원 호환성의 증거는 아니다.

## 항목 추가 틀

ID / 가정 / 상태 / 영향 / 안전한 기본값 / 확인 책임·시점 / 근거 / 관련 ADR / 해소 결과를 남긴다. 해소된 항목은 삭제하지 않고 이력을 유지한다.

## PRD 작성에 따른 갱신 (2026-11-03)

- A-005: **범위 가정 대체**. 일반 이용자 계정·별도 DB의 필요성은 여전히 미확정이나, MVP 관리자 기능은 사용자 요구로 포함한다. ADR-005에 따라 서버 인증·권한 검증을 필수로 하며 기술 방식은 P1에서 결정한다. 과거 가정은 이력으로 보존한다.
- A-009: PRD의 최근 구간·점수 범위·성능 예산·사용성 목표는 제품 제안이며 검증 실적이 아니다. ADR-006 및 P3/P5에서 확정·검증한다.
- A-010: 운영 주체·문의 경로·개인정보 처리 항목/보관·개별 법적 표시 적용 여부는 미확인이다. 개인정보 최소 수집을 기본으로 하고 P5 공개 전 검토한다.
- A-011: 등록 이력과 팀별 경기 귀속을 승인된 형식으로 표현할 수 있는지 P2 검증 예정이다. 현재는 가상 fixture만 허용하며 출전 이력으로 등록을 추정하지 않는다.

## 데이터 권리 검토 갱신 (2026-11-03)

- A-012: 공식 API의 존재·공급자·인증 자격·약관·저장/가공/노출 권한은 미확인이다. KBO 고지의 API 언급만으로 승인하지 않는다. 기본값은 연결 없음이다.
- A-013: 계약 증빙 보관소·법무 검토자·데이터 권리 담당자 실명은 미지정이다. 가상 fixture도 미작성으로 개별 제작 이력 검수가 남아 있다. 공개 전 RELEASE_GATES의 담당자·증빙·산출물 검수를 완료한다.
- A-001/A-003의 권한 미확인은 유지한다. DATA_RIGHTS 대장의 A/B/C pending 및 자산별 pending을 해소하기 전 실제 데이터/자산을 도입하지 않는다. ADR-007을 적용한다.

## 아키텍처 결정에 따른 갱신 (2026-11-03)

- A-004: 구조 선택은 ADR-008로 채택. ARCHITECTURE의 버전은 공식 레지스트리 조회값이며 설치·전체 peer graph·빌드 호환성은 미검증이다. P1에서 정확한 lockfile과 strict/lint/build로 확인한다.
- A-005: DB 미정 가정은 ADR-008로 대체. fixture는 입력과 재현 기준으로 유지하고 P2 이후 영속 게시·복구·감사는 PostgreSQL을 사용한다. P0 DB 설치·실행은 하지 않는다.
- A-014: 관리자 인증 라이브러리·버전·운영 계정·세션/감사 보관 기간은 미확정이다. DB 서버 세션·초대 관리자만을 제안하며 P1 보안·호환성 검증 전에는 전체 관리자 접근을 거부한다.
- A-015: 입력 5 MiB/50,000행, 검색 길이 100자, JS gzip 200 KiB/차트 150 KiB는 설계 기본값이며 실측 한도가 아니다. P2 입력 검증·P5 성능 측정으로 확정한다.
- A-016: 컨테이너 이미지 digest·배포 호스트·백업 위치·보관/복구 목표는 미확정이다. P5 실행·복구 검증 전 공개 출시를 보류한다. Node 26.11.0은 로컬에서 확인했으나 전체 스택 조합은 미검증이다.


## v1 계약 작성에 따른 갱신 (2026-11-03)

- A-009: ADR-009로 페이지 크기·통계 조회용 최근 N=10/5/10을 채택한다. 기세 모델의 N/최소 표본/산식·점수 범위는 P3 미결정으로 유지하며 API model_pending으로 노출한다.
- A-011: 등록 snapshot_on/effective_on/status 및 경기 당시 team_id를 DATA_DICTIONARY에 정의했다. 실제 공급자의 제공 가능성은 여전히 미확인이다. 등록 미상은 unknown이며 출전/등번호로 추정하지 않는다. 가상 fixture와 FK 검증은 P2 미실행이다.
- A-015: 입력5MiB/50,000행·검색100자·목록최대20·통계N최대100은 ADR-009의 계약 제한으로 채택했다. 실제 부하/메모리 성능·JS/차트 예산은 P5 미검증이다.
- A-017: 공급자가 completed_at, 행별 GS/role, 안정 선수/경기 ID mapping, 정정 revision, 상세 타석 수치를 제공하는지 미확인이다. 현재 자체 fixture로 계약을 재현하며 필수값 없는 실제 어댑터는 게시 거부한다. 최소 nullable 카운트는 결측 사유와 함께 null로 보존한다. 실제 공급 도입 전 계약/권리·스키마 적합성을 검토한다.
- A-018: source별 자동 sync 주기·SLA·운영 rate limit은 미확정이다. 외부 호출/자동 갱신 없음, DEMO lastSuccessfulSyncAt은 fixture 게시 성공 시각만 뜻한다. SLA 없는 임의 지연 판단은 하지 않는다.
- A-019: 요청 시간 초과15초·모바일768px breakpoint는 ADR-009 화면 계약 기본값이며 사용성/실측 성능 검증은 P4/P5에 남는다. 모델·법무·인증·출시 미결정 사항은 기존 A-006/010/012~016을 유지한다.

## P1 추가 확인/미확인 (2026-11-03)

- 이번 요청의 설치 완료 기준에 따라 P1 의존성 설치는 승인된 것으로 해석한다. 외부 야구 데이터 수집은 여전히 금지다.
- 관리자 인증 공급자·세션·DB는 미구현이며 모든 관리자 기능을 제공하지 않는다.
- 공개 출시·운영 문의·실제 데이터 공급 권리는 미확정이다. 이번 결과는 개발 뼈대다.
- Node 26.11.0/pnpm 12.10.1은 로컬 실행값이며 다른 OS/런타임 호환성은 검증하지 않았다.

## UI 시스템 추가 (2026-11-03)
- 시스템 한국어 글꼴 가용성과 굵기는 OS별로 다르다. 다운로드·재배포하는 폰트 자산은 없다.
- 실제 MomentumGauge 점수 표현은 A-006 모델 확정 후 구현한다. 현재 역할별 산정 대기 상태만 제공한다.
- 자동 접근성 검사는 Chromium/axe 기준이며 스크린리더 실기기 검증과 모든 OS 글꼴 검증은 남아 있다.

## DB 스키마 초안 (2026-11-03)
- A-020: Docker/psql은 현재 실행 경로와 일반 설치 경로에서 확인되지 않았다. 운영 PostgreSQL URL은 제공되지 않았으며 추정하지 않았다.
- A-021: Prisma 설치는 자동 승인 검토가 P0 설치 금지를 근거로 거절했다. 첫 SQL·스키마는 검증 전이며 호환성/DB 적용 성공을 가정하지 않는다. SCHEMA.md의 남은 제약과 통합 테스트를 완료해야 한다.

- 2026-11-03 API 단계: Prisma 패키지·생성 client 부재를 로컬에서 확인. 패키지 설치 금지를 유지한다. DB 실연결 및 실제 데이터 모드는 미검증/미구현이며 fixture 읽기만 활성이다.

- 2026-11-03: 가상 전시 경기 규칙으로 양 팀 각각 27아웃, 동점 허용을 채택했다.
  KBO 공식 경기 규칙이나 실제 일정·기록을 재현하지 않는다. 시즌/정규시즌 표기는
  API scope를 검증하기 위한 가상 분류다. 경기 모델의 사실은 fixture 내부에만 유효하다.
- 기존 `prisma.config.ts`는 `prisma/config`를 참조하지만 package.json과 설치 상태에
  Prisma 런타임이 없다. 패키지 설치 금지 조건 때문에 PostgreSQL 실행 검증은 하지 않는다.

## ingest adapter 추가 (2026-11-03)

- 실제 공급자·계약·인증·필드 권한은 여전히 미확인이다. mock 권리 기록은 테스트 전용이다.
- 권리 registry는 신뢰 가능한 서버 저장소에서 제공해야 한다. 실제 PostgreSQL registry,
  영속 staging 및 원자 게시 연결은 미구현이며 현재 실제 공개 경로는 비활성이다.

## 샘플 ingest (2026-11-03)

- 관리자 계정 시스템이 없어 이번 샘플 접근은 운영자가 서버에 직접 설정하는 단일 bearer capability로 제한한다.
  실제 운영 사용자/역할 증명·SSO·회수/감사 시스템은 미확인/미구현이다. 미설정은 업로드 거부다.
- 실제 업로드 데이터의 권리를 자동 판정하지 않는다. 신뢰되는 자체 샘플의 checksum만 허용한다.
- staging은 단일 서버 로컬 파일이며 영속 디스크/백업/쿼터/보관 정책은 미확정이다.
- 전체 타입 검사와 빌드는 기존 Prisma 패키지 부재 장애를 해결하기 전 통과로 주장할 수 없다.

## 관리자 승인 DEMO pipeline (2026-11-03)

- 승인된 자체 제작 샘플은 2026 시즌만 지원한다. sourceId/licenseId는 서버가 지정하며 파일에서 받지 않는다.
- DEMO의 game_id는 공급자 외부 경기 ID를 그대로 정규화한 안정 ID다. 날짜/팀 이름으로 ID를 생성하지 않는다.
  doubleheader_no 기본값 1, 두 번째 경기는 별도 game_id와 2를 사용한다.
- played_on은 계약상 공식 경기 귀속 날짜이며 재개 시 로스터도 이 날짜를 기준으로 한다.
  resumed/official_final은 향후 공급자 adapter가 승인 계약으로 확정해야 하는 값이다. 현재 업로드는 고정 DEMO 샘플만 허용한다.
- DEMO 전용 합계는 타자/선발/불펜 역할을 분리한다. 기세 점수 모델은 채택 전이므로 새 점수를 만들지 않는다.
  정정 시 기존 점수 캐시를 무효화하고 영속 RECALCULATE 이벤트와 재집계 결과를 원자적으로 기록한다.
- 단일 로컬 파일 저장소는 운영 다중 호스트·장기 대용량 저장소가 아니다. 정전 시 파일 시스템 내구성과
  파일 소유자의 직접 변조 방어는 운영 DB/백업 체계의 후속 과제다. 읽기 오류는 빈 데이터로 대체하지 않는다.

- 2026-11-03 타자 통계: 제공자 공식 PA의 사건 분류는 미확인이다. 현재 DEMO 입력 PA는 세부 항목 부족으로 unverifiable일 수 있다. 로컬 PA 검증 계약과 기본 표본 기준은 STAT_FORMULAS.md 참조. 실제 공급자 연결 전 정의 매핑 확인이 필요하다.

- 2026-11-03 투수 통계: 실제 공급자의 BB/IBB 포함 정의와 리그·시즌별 FIP 상수는 미확인이다.
  로컬 라이브러리는 출전마다 walkDefinition을 명시하게 하고 FIP를 비활성화한다.
  호출자는 최신 확정 revision만 넘겨야 한다. 기존 업로드 샘플의 제한된 필드는 결측을 유지하며 새 필드를 추정하지 않는다.
  이번 구현은 계산 라이브러리이며 공개 API/화면·실제 공급자 adapter 연결은 포함하지 않는다.

- 2026-11-03: 로스터의 공급자별 완전성·유효기간·1군 분류 계약은 미확인이다.
  현재 rosters는 명시적 1군 DEMO 입력으로만 취급한다. 유효기간 없는 명단을 다음날까지 연장하지 않는다.
  48시간 stale 임계값은 임시 정책이며 무경기/오프시즌 운영 SLA가 아니다. 실제 일정 없이 시즌 중 여부를 판단하지 않는다.
  알림 전송·라이선스 API·자동 스케줄은 연결되지 않았다. 기존 고정 샘플 이외 업로드 제한은 유지한다.

## 순수 기세 계산 구현 (2026-11-03)

- `momentum.ts`는 제공자가 고정 release의 최신 확정 revision을 해소했다는 `revisionsResolved` 선언을 요구한다. 중복 확정 경기/한 경기 혼합 투수 역할은 거부하며, revision history를 직접 조회·선정하지 않는다.
- `coverageComplete`는 해당 입력의 선수/역할 출전 로그 및 cohort 원본의 완전성에 관한 호출자 선언이다. 함수는 누락된 경기를 발견하거나 실제 공급자 권한을 인증할 수 없다. 공급 adapter에서 검증된 입력만 전달해야 한다.
- roster의 명시 상태·사유·출처를 설명에 남긴다. 미등록/unknown만으로 부진이나 감점을 만들지 않으며 경과일 및 표본 게이트가 eligibility를 결정한다.
- 현재 fixed config 이외의 사용자 설정/실데이터 보정, 과거 점수 저장, API DTO 연결과 화면 검증은 미구현이다. 표시용 반올림은 계산 라이브러리에서 수행하지 않는다.

## 내부 표시 결과·골든 fixture 후속 (2026-11-03)

- ADR-016에 따라 calculateMomentum은 내부 표시 결과를 제공한다. scoreMomentum의 원점수 산식은 그대로이며 표시 반올림을 분리한다.
- 상승/하락 60/40 경계의 실제 리그 타당성은 미확인이다. DEMO 라벨이며 예측 확률로 해석하지 않는다.
- 최신 정정 release를 전달하는 자동 실행·공급 adapter는 후속 작업이다. 순수 함수는 수정된 입력을 전달받을 때 재계산하며 스스로 외부 변경을 감시하지 않는다.

- A-017 (채택한 DEMO 기본값): 낮은 신뢰도와 로스터 등록 미확인 선수는 본 순위에서 제외하고 별도 반환한다. deltaScore의 유효 이전 결과는 같은 모델의 순위 적격 snapshot으로 정의했다. 실제 공급자 입력 완전성/BB 정의/로스터 유효기간 보장과 모델 실증 보정은 미확인이다. 기본 ingest 예시는 표본과 feature가 부족하므로 점수 null이 정상이며, 점수 정정 수락 검증에는 자체 제작 cohort fixture를 사용한다.

- A-018: reports/MOMENTUM_VALIDATION.md의 분포/민감도/순위는 합성 fixture만 대상으로 한다. 실제 사용 권리, 시점별 revision/roster와 충분한 역할별 historical coverage는 확인되지 않았다. CLI의 권리/coverage 선언과 100경기 floor는 외부 검증을 대체하지 않는다. 높은 confidence도 예측 확신이 아닌 표본 등급이다.

- 홈의 마지막 경기일은 fixture 완료 경기의 최종 날짜이며, 데이터 기준 시각/fixture 제작 시각과 다를 수 있다. 실시간 시즌 진행·오프시즌 여부는 확인할 수 없어 항상 최근 출전 기준임을 안내한다.
- 홈 검색은 선택한 역할의 fixture 전체 선수명/팀명 부분 일치 검색이다. 실시간 외부 선수 검색이나 현재 등록 선수 목록이 아니다.

- 선수 탐색은 2026 정규시즌 canonical DEMO만 제공한다. 현재 등록·포지션·등번호 유효기간을 확인할 공급 계약이 없으므로 관련 필터/이력을 제공하지 않는다. fixture 이름은 가상 식별명이며 한국어 동명이인 검색은 복제 fixture로 검증한다. 실제 공급 데이터의 이름/포지션 품질 검증은 후속 계약 단계다.

- 타자 상세의 현재 엔트리·주 포지션·사진 권리는 미확인이다. 중립 이미지와 미확인 안내를 사용하며 최근 출전만 설명한다. DEMO 원시 HBP/SF는 미제공으로 유지하고 현재 컨디션이나 미래 성과를 주장하지 않는다.

- 투수 상세는 DEMO 정규시즌만 지원한다. 공급자의 실제 등판 역할/투구수/구종/구속/개인 승패/HLD/SV 공급 여부와 권리는 미확인이다. 합성 line의 역할만 사용하고 미제공 데이터는 N/A 또는 영역 숨김으로 처리한다. 미래 성과·건강·현재 로스터를 추정하지 않는다. 혼합 선수 가상 등판 배정은 실제 운용의 재현을 주장하지 않는다.

- 2026-11-03 rankings: 운영 DB 랭킹 adapter는 현재 미연결이다. 게시 pipeline JSON을 승인된 DEMO 원천으로 사용한다. 과거 전체 publication manifest와 운영 SQL 정렬 검증은 미확인/미구현이며 수락 완료로 간주하지 않는다.

- 2026-11-03 비교: 승인된 공급 데이터가 없어 단일 canonical DEMO release만 사용한다. 선수별 별도 업데이트 시점과 실제 엔트리/결장 사유는 미확인이다. 공통 기간은 최근 달력일 대신 역할별 5/10출전 또는 시즌으로 채택했다(ADR-023).

- 차트의 날짜/상대 필터는 표시 필터로 채택했다(ADR-024). 해당 필터로 재집계한 통계가 필요한지는 미확인이다. 외부 라이선스 exportAllowed 저장/검증 adapter는 미연동이며 실제 데이터 내보내기 승인을 추정하지 않는다.

- 2026-11-03 UX QA: 공개 도메인(SITE_URL), 호스팅 로그 항목·보유 기간, 운영 문의처와 자산 권리 최종 승인자는 미확정이다. DEMO는 검색 비노출을 기본 채택했다. privacy/data-terms는 최종 법률 문서가 아닌 placeholder다.
